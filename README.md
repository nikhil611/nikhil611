## 🚀 Featured Projects

### 🎙️ MoM — Minutes of Meeting Generator
**`Python` `FastAPI` `faster-whisper` `NVIDIA NeMo` `Llama 8B` `Docker`**

> End-to-end meeting intelligence pipeline — from raw audio to polished MoM PDF/DOCX

- 🔊 **3-filter FFmpeg audio chain**: 100Hz high-pass → −30dB FFT denoiser → 10:1 noise gate at −36dB before Whisper
- 🤖 **Llama 8B runs 3 tasks in one pipeline**: MoM summarisation (300s), speaker name extraction (60s), ASR error correction (120s) — across **6 languages including Hinglish**
- 🐳 **5 Docker containers** with GPU reservation for speech/NeMo; CPU Llama pinned to 16 OMP/MKL threads; health checks every 10s
- 🔁 Each AI service retries independently at 2s, 4s, 6s on failure — handles recordings up to 10 minutes
